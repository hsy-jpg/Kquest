# K-Quest

You are a product designer building a gamified travel app for foreigners visiting Korea.

Create the main app structure.

App concept:

- Users complete real-world "quests" in Korea

- Similar to Duolingo but for travel experiences

- Users earn XP, badges, and levels


Create a mobile app with bottom navigation including:

1. Home

2. Explore (map-based)

3. Community

4. Profile


Requirements:

- Clean and modern UI

- Slightly playful (like Duolingo)

- Focus on usability for non-Korean users

- All text in English

Do not go deep into details yet. Just design the main structure and layout.
